# logic/defaultLogic.js

Import brut du fichier `default.logic` du randomizer.

Charge le contenu de `SubModule/randomizer/RandomizerCore/Resources/default.logic` via la query Vite `?raw` et le réexporte en `default` (une simple `string`). C'est la source de logique par défaut consommée par `parseLogic()` et `parseDirectives()`.
